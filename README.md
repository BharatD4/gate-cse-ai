\# GATE CSE AI



An AI-powered GATE CSE preparation platform designed to help students practice questions, track performance, and prepare efficiently for the GATE Computer Science examination.



\## 🚀 Live Demo



\*\*\[Open GATE CSE AI](https://gate-cse-ai.expo.app)\*\*



\## ✨ Features



\- 📚 GATE CSE question practice

\- 🔎 Search and filter questions

\- 🏷️ Subject, topic, year and difficulty filters

\- 📖 Detailed solutions and concepts

\- 💡 AI-powered hints

\- 🔖 Bookmark questions

\- 📊 Performance analytics

\- 📝 Mock tests

\- 💾 Local progress and attempt tracking

\- 📱 Responsive web interface

\- ☁️ Production deployment with Expo



\## 🛠️ Tech Stack



\- React Native

\- Expo

\- Expo Router / Navigation

\- AsyncStorage

\- JavaScript

\- EAS Hosting
